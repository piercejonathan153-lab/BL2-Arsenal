# Changelog

## v1.0.12
- Drop weights now use the same scale as TPS's own loot (many items were ~100x rarer than intended).
  BL2 items together never outweigh what a loot list already drops.
- New `b2p drops` console command: checks every item's loot entries and odds in the live game.
- Zero-G Longshot (Longbow) fires BL2's real 3D voxel arrow model.
- Pixel Pummeler (Blockhead) fires proper Minecraft fire blocks.
- NEIGHPLOSION!!! shoots unicorns again, with a rainbow splat decal.
- Effervescent (rainbow) rarity animates on cards, backpack tiles, equipped slots, loot beams, HUD icon and HUD header.
- Talking-gun subtitles; Scarlett's Greed pickup line.
- Fixes: Lilith grenade/shield materials, slag decal, options-menu crash.
